# Mnemonica

This is a program that applies a shuffling to a files contents. The goal being obfuscation withouth changing the filename or extension.

There are going to be better ways to do this, but this is a simple static method for shuffling the bytes in the file. 

The method of shuffling falls in line with a method that scales and falls in line with an "algorithm" Juan Tamariz derived for shuffling a deck of cards.
